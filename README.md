# Игры разума (Brain Games)

[![Actions Status](https://github.com/Vladi11/fullstack-javascript-project-44/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/Vladi11/fullstack-javascript-project-44/actions)

## Описание проекта

«Игры разума» — это набор из пяти консольных мини-игр, построенных по принципу популярных мобильных приложений для прокачки мозга. Каждая игра задает вопросы, на которые нужно дать правильные ответы. После трех правильных ответов подряд игра считается пройденной. Неправильные ответы завершают игру и предлагают пройти ее заново.

Проект разработан в рамках учебной программы на платформе [Hexlet](https://ru.hexlet.io/programs/fullstack-javascript).

### Список игр

* **Проверка на четность (`brain-even`)** — определение четности случайного числа.
* **Калькулятор (`brain-calc`)** — вычисление результата арифметического выражения (сложение, вычитание, умножение).
* **Наибольший общий делитель (`brain-gcd`)** — нахождение наибольшего общего делителя двух случайных чисел.
* **Арифметическая прогрессия (`brain-progression`)** — поиск пропущенного члена в последовательности чисел.
* **Простое ли число? (`brain-prime`)** — определение того, является ли предложенное число простым.

## Минимальные системные требования

* **Node.js**: версия 20.19.0 или выше
* **npm**: версия 9.0.0 или выше
* **GNU Make**: для удобного запуска команд через `Makefile` (опционально)

## Установка

1. Клонируйте репозиторий на локальный компьютер:

```bash
git clone https://github.com/Vladi11/fullstack-javascript-project-44.git
```

2. Перейдите в директорию проекта:

```bash
cd fullstack-javascript-project-44
```

3. Установите зависимости проекта:

```bash
make install
```

4. Выполните глобальную линковку пакета для запуска игр из любой директории по имени команды:

```bash
make link
```

## Запуск игр и демонстрация игрового процесса

После выполнения `npm link` игры можно запускать напрямую через терминал по их названиям или с помощью команд `Makefile`.

### Приветствие (Знакомство)

Базовая команда для знакомства с пользователем.

Запуск:
```bash
brain-games
```

---

### 1. Игра «Проверка на четность»

Суть игры: пользователю показывается случайное число. Необходимо ответить `yes`, если число четное, или `no` — если нечетное.

Запуск:
```bash

```
